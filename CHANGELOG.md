# Changes

Each stable release has a version, and its section here becomes its release notes. Dev builds don't change the version.

## 0.0.5

- First numbered release. From here the version goes up only with a stable release, so each one bundles notable changes.
- The launcher and updater show a stable release by its version, and a dev build as "build N, after version X".
- Fulldex 8 November: a Manage Saves page for each game (save states, backups, export and import), ROM hacks with saves of their own, patch files put on your own clean ROM, and fast forward that stays on.
- Platinum PC port v0.2.1: fixes a crash in the Battle Hall. Its saves stay in the DS format.
- Gen1Recomp: the latest upstream updates.
